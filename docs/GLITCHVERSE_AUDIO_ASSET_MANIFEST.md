## 1. Overview & Identity Direction

This curated audio collection establishes the auditory environment of *GlitchVerse*: a restrained, clinical, tense research facility dealing with anomalous reality desynchronization. Instead of arcade-like or distracting sound effects, these assets prioritize cold, tactile feedback, subtle background resonance, and focused mechanical cues.

A total of **11 individual audio assets** and **3 verified license documents** have been staged in `assets/audio/ui_curated/`. All assets were verified through official source packages and test-loaded directly in the Godot 4.7.2 engine.

## 5. UI Audio Integration Status (Completed in Phase 3)

1. **Service Architecture (`res://scripts/ui/ui_audio.gd`):**
   - Automatically initializes and registers all 11 curated streams into the engine `AudioManager` via `AudioManager.register_event(event_name, stream, true)`.
   - Replaces synthetic placeholders with genuine CC0 WAV/OGG streams while preserving identical call sites.
   - Provides safe fallback to scene-local audio players when `AudioManager` is unmounted in isolated tests.
   - Features built-in hover rate-limiting (45ms cooldown) and metadata flag checks (`ui_audio_bound`) to strictly prevent duplicate connections and audio stuttering.

2. **Screen Integration Coverage:**
   - **Main Menu (`main_menu.gd` / `.tscn`):** Navigation button hover/focus tick (`ui_hover_tick.ogg`), selection click (`ui_click_mechanical.ogg`), start game confirm (`ui_confirmation_chime.ogg`), modal close back cue. Added `%MasterSlider` and `%SFXSlider` with live `AudioServer` volume adjustments.
   - **Pause Menu (`pause_menu.gd` / `.tscn`):** Tactical hover/click feedback across all buttons, in-place volume sliders for Master, SFX, and Music mapped to `AudioServer`.
   - **Level Complete (`level_complete.gd` / `.tscn`):** Completion fanfare hook (`play_level_complete()`), button hover/click, next level confirm.
   - **Game Over (`game_over.gd` / `.tscn`):** Containment breach alarm cue (`play_game_over()`), retry click, return to menu back cue.
   - **Final Victory (`final_victory.gd` / `.tscn`):** Campaign victory presentation hook (`play_victory()`), replay confirm, return to menu back cue.
   - **In-Game HUD (`in_game_hud.gd` / `.tscn`):** Low-health emergency warning alert (`ui_error_alarm.ogg`), transient breach alarm notifications, exit unlocked and relay restore event SFX.
   - **UI Preview (`ui_preview.gd` / `.tscn`):** All 6-screen preview switcher buttons and simulated tools wired with audio feedback.

3. **Validation & Test Coverage:**
